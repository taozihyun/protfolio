# ARIA Interactive Resume

Premium interactive web resume for 郭耀薇（ARIA），focused on TOB sales,
key account development and business development.

## Development

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Production

```bash
pnpm build
pnpm start
```

## Content

Resume content and case-study data live in `lib/resume-data.ts`. The downloadable
PDF is stored at `public/aria-resume.pdf`.
